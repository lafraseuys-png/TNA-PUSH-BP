Reporting Structures

Last change: Admin · 14 Oct 2026 09:12
MOCKUP: sample data only. Nothing on this page reads from or saves to the database.

Choose how this company's reporting works by default. Every connected module (Employee Master, TNA, HR, ESS, Employee Costs, Leave) uses this one rule, so a manager sees the same people everywhere.

Direct Reportees

A manager sees themselves and the people whose Reports To is them. One level only.

Best for: small teams, supervisors, farms with flat crews.

By Department

A user sees everyone in the departments assigned to them, including sub-departments added later.

Best for: HODs, HR officers, payroll clerks, site admins.

Reporting Lines (Top-Down)

A manager sees their whole downline: their reports, their reports' reports, and so on down the tree.

Best for: corporates, multi-level operations, executives.

How a user's scope is decided (top wins)
  1. Tenant Admin / God Mode: sees everyone.
  2. User override: set on one user in User Access > Data Scopes.
  3. Role's Scope Profile: from the table above.
  4. Company default: the Structure Model tab.
